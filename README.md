# 치지직 실시간 채팅 멀티뷰 (최대 6분할)

단일 Python 파일로 실행하는 치지직 최대 6분할 실시간 채팅 & 영상 멀티뷰입니다.

## 실행 방법
```bash
python chzzk_chat.py
```

## 주요 기능
- 최대 6개 채널 동시 실시간 채팅 (도네이션·스트리머·매니저 강조 및 상단 고정 칸)
- 실행 시 GitHub 최신 버전 자동 업데이트 (`chzzk_update.json` 설정 저장, `v` 메뉴에서 구버전 선택 시 버전 고정 및 `a` 키로 자동 업데이트 켜기/끄기)
- **채팅 모드 ↔ 시청 모드 전환**:
  - 화면 좌측 상단(`top: 58px`) **접이식 모드 전환 탭** (`▶` 클릭 펼침, 시작 시 안내 말풍선 제공)
  - 채팅창별 상단 미니 영상 미리보기(`📺`, 360p/480p/720p/원본) 및 더블클릭 시청 모드 진입 (`Esc` 복귀)
- **시청 모드 (창모드 기본 · 상단 HUD `⛶ 전체화면` 토글 지원)**:
  - 상단 HUD에서 여러 방송을 **다중 분할 화면**으로 추가/해제 및 드래그 순서 변경 (분할 수에 따른 자동 화질 조정·상태 프리셋 저장)
  - **◫ 채팅 오버레이 모드**: 영상을 화면 전체로 깔고 채팅을 반투명 오버레이로 표시 (`🎨` 배경 투명도·글자 테두리 조절, `Alt` 홀드 시 뒤 영상 클릭 통과)
  - **방별 채팅 선택 · 통합(`✔ 합치기`) 보기** 및 방 색상 태그 구분
- **라디오 모드 (특정 방송 소리만 듣기)**:
  - 상단 HUD 채널 칩 우클릭 → `🎧 소리만 켜기 (라디오)` 선택 시 화면 분할 없이 오디오 전용 트랙 우선 재생(미제공 시 최소 화질 폴백)
  - 영상 우측 상단에 **반투명 원형 라디오 배지**(최대 3글자, 좌클릭 즉시 음소거 토글, 우클릭 라디오 끄기·영상 전환·볼륨·`↗ 해당 채널로 이동`) 표시
- **타임머신 · 미세 싱크 · 오디오 제어**:
  - `-10s` / `+10s` / `● LIVE` 탐색 및 타임라인 슬라이더·가로 드래그 타임머신
  - `-0.5` / `+0.5` 배속 미세 싱크 맞춤 (`Shift+클릭`: `±0.2초`)
  - 우측 접이식 전역 툴바(`◀` 근접 돌출: 설정·쿠키·글자 크기·전체 마스터 볼륨) × 방송별 개별 볼륨/음소거 연동
- **영상 로드 안정성**: 백업 CDN 폴백, 일시 오류 자동 재시도 및 클릭 재시도 지원
- **네이버 로그인 쿠키 설정** (`c` 또는 웹 `🔑` 버튼, 성인 인증 방송 시청/채팅용 로컬 저장)
- 이름 / 32자리 채널 ID / 치지직 URL 입력, 웹 편성 관리(`E`), 최근 스트리머 조합 9개 저장
