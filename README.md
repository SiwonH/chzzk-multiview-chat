# 치지직 실시간 채팅 멀티뷰 (최대 6분할)

단일 Python 파일로 실행하는 치지직 6분할 실시간 채팅 멀티뷰입니다.

## 실행 방법
```bash
python chzzk_chat.py
```

## 주요 기능
- 최대 6개 채널 동시 실시간 채팅 (도네이션·스트리머·매니저 강조 및 상단 고정 칸)
- 실행 시 GitHub 최신 버전 자동 업데이트 (`chzzk_update.json` 설정 저장, `v` 메뉴에서 구버전 선택 시 버전 고정 및 `a` 키로 자동 업데이트 켜기/끄기)
- 방송별 **상단 미니 영상 미리보기** (`📺`, Shift+클릭 전체 토글, 360p/480p/720p/원본 화질 선택, 지연 최소화)
- 영상 **더블클릭 전체화면 집중 모드** (큰 영상 원본 화질·음소거 자동 해제, 채팅창 경계선 드래그 너비 조절·저장, 복귀 시 기존 상태 복원)
- **네이버 로그인 쿠키 설정** (`c` 또는 웹 `🔑` 버튼, 성인 인증 방송 시청/채팅용 로컬 저장)
- 스트리머 이름 클릭 시 해당 치지직 방송 페이지 새 탭 열기
- 우측 상단 **접이식 서랍형 전역 툴바** (`◀` 근접 돌출, 초기 안내 말풍선 및 바깥 클릭 자동 접힘, 설정·쿠키·글자 크기)
- 이름 / 32자리 채널 ID / 치지직 URL 입력 및 웹 편성 관리 (`E`)
- 최근 스트리머 조합 9개 저장 (숫자 빠른 입력 & 클릭 선택)
